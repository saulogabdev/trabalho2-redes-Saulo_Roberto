# Exercício 2 - Dozzle via Docker Compose

Este projeto disponibiliza o **Dozzle**, uma aplicação web moderna com interface escura e em tempo real para monitoramento e análise de logs de containers Docker.

## 🛠️ Tecnologias Utilizadas
* **Aplicação Principal:** Dozzle (`amir20/dozzle:latest`)
* **Orquestrador:** Docker Compose

## 🚀 Como Executar
1. Garanta que o Docker esteja ativo na máquina host.
2. Na raiz do projeto, execute:
   ```bash
   docker compose up -d
